StarkHacks

April 2026

At StarkHacks, the largest hardware hackathon in the US, I worked in a team of 4 to build PatchWork, an on-device AI system that gives robotic arms the ability to detect and recover from their own failures in real time. The system accepts natural language commands, converts them into a sequence of executable robot skills, and monitors each action through a vision-language model (VLM) running entirely on AMD hardware. If a step goes wrong, PatchWork identifies the root cause, applies the appropriate correction, and retries without any cloud dependency or human intervention.

My contributions centered on the backend systems. The core of my work was the real-time robot operator dashboard, which displays a live camera feed of the LeRobot SO-101, a ReAct agentic loop phase indicator (Plan → Act → Observe → Reflect → Patch), a step-by-step execution pipeline with pass/fail/patched states, live VLM inference latency on an AMD Ryzen AI laptop benchmarked against the CPU baseline, a live execution trace table of recent robot events, and a patch memory table tracking stored fixes and their application count. For real-time visual monitoring, I configured 2 USB webcams to simultaneously observe the SO-101 follower arm's gripper and shelf target. To support repeatable execution, I also designed and modeled a custom shelf layout and slot fixtures in Autodesk Fusion 360 to provide structured placement targets for the arm.

🏆 Honorable Mention — Best Use of AMD Technology 🏆
