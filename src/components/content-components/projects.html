Line-Following Robot Car

April 2026 – June 2026

This project involved designing, assembling, and programming a fully autonomous line-following robot as part of EE201 at the University of Washington. Working in a team of 3, we built a robot that uses an array of 7 photoresistors to detect a black line on a white surface, with a PID control loop written in C++ on an Arduino Mega continuously adjusting the left and right motor speeds to keep the robot centered on the track. The weighted-average error calculation across the sensor array produces a smooth, continuous position signal, which the PID controller uses to compute corrective turn rates in real time.

A key challenge was handling the track's variety of turn types, from gentle S-curves to tight 90° bends and a near-180° turn. To solve this, we implemented an edge-triggered pivot system that detects when the line reaches the outermost sensors and transitions the robot into a fixed-speed pivot maneuver, bypassing PID control for the duration of the sharp turn. Segment-aware speed logic and a streamlined calibration routine were also implemented to boost velocity on straights, slow through complex turn sequences, and minimize startup time before each run.

Beyond the core software, the project required significant hardware work. We designed a custom photoresistor PCB in KiCad, modeled a 3D-printed component in Autodesk Fusion 360 to improve sensor positioning and chassis organization, and fabricated a light shield around the sensor array to reduce the impact of ambient lighting and shadows on photoresistor readings. The motor power supply was upgraded and separated from the logic supply to eliminate brownout resets at high speeds. We also integrated a TM1637 7-segment display that shows live SPID values, allowing on-track tuning of the proportional, integral, and derivative gains via potentiometers without needing a serial monitor or code reflash between runs.

The robot finished in 8th out of 36 teams with a time of 43.46 seconds, completing the full course in a competitive field where 4th-8th place were all within 4 seconds of each other.

FPGA Connect 4

February 2026 – March 2026

This project involved designing and implementing a fully functional 2-player Connect 4 game on a DE1-SoC FPGA board using SystemVerilog. At the core of my system's implementation, Finite State Machines (FSMs) were used to manage all aspects of gameplay, from tracking which player's turn it was, to determining when a player had won or when the board had filled up. Clock-based timing was also incorporated to control the pacing between rounds, giving the game a polished and smooth flow.

Beyond the core deliverables of this EE 271 final project, I extended the scope of my project to include a tournament-style format where players compete across multiple rounds, with the system keeping track of each player's wins and advancing through the competition accordingly.

The live game state is displayed on both a 7-segment display on the DE1-SoC board and a 16x16 bi-color LED array, with each player assigned a distinct color so the board is easy to read at a glance. To verify that the hardware logic behaved correctly in every possible scenario, I wrote extensive SystemVerilog testbenches for all modules that I implemented, testing various edge cases from win conditions in all directions, to invalid inputs, and point tracking within each tournament.

The end result of this project was a complete, playable hardware Connect 4 game system that showcased fundamental digital design principles, from FSM logic to real-time display output.

Quartus SystemVerilog ModelSim

Sliders

Released Click on the Sliders logo above to play!

This personal project focuses on the creation of a sliding puzzle game, "Sliders". Players can choose from difficulty levels with grid sizes ranging from 3x3 (easiest) to 7x7 (hardest). The goal is to slide the numbered tiles into a specific randomized order, which is different for each game played. The numbered tiles aren't necessarily in a numerical sequence; the orders of the starting board and finishing board will vary with each new round. This type of puzzle offers an engaging challenge with various levels of complexity, suitable for both beginners and puzzle enthusiasts.

The game has been released as of December 2025, with more updates to come in order to improve user experience and engagement with this strategy-based puzzle game.

Jumbled Blockers

In Progress Target Release: Summer 2026

"Jumbled Blockers" is a brain-stimulating puzzle game where the objective is to arrange colored discs onto matching color-coded poles. Players can only move the top disc on any pole, one disc at a time. The game allows players to choose the difficulty by selecting how many poles to sort discs from, ranging from 4 to 7 poles. The number of discs a pole can hold is also determined by the difficulty level (in a 1:1 ratio).

The objective is to sort all the discs by color in as few moves as possible while keeping track of the limited pole capacity and disc order restrictions. Each puzzle is timed, adding an extra layer of competition. The game is intended to be engaging, helping players improve their problem-solving skills while offering various levels of difficulty.
