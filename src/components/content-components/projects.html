FPGA Connect 4

February 2026 – March 2026

This project involved designing and implementing a fully functional 2-player Connect 4 game on a DE1-SoC FPGA board using SystemVerilog. At the core of my system's implementation, Finite State Machines (FSMs) were used to manage all aspects of gameplay, from tracking which player's turn it was, to determining when a player had won or when the board had filled up. Clock-based timing was also incorporated to control the pacing between rounds, giving the game a polished and smooth flow.

Beyond the core deliverables of this EE 271 final project, I extended the scope of my project to include a tournament-style format where players compete across multiple rounds, with the system keeping track of each player's wins and advancing through the competition accordingly.

The live game state is displayed on both a 7-segment display on the DE1-SoC board and a 16x16 bi-color LED array, with each player assigned a distinct color so the board is easy to read at a glance. To verify that the hardware logic behaved correctly in every possible scenario, I wrote extensive SystemVerilog testbenches for all modules that I implemented, testing various edge cases from win conditions in all directions, to invalid inputs, and point tracking within each tournament.

The end result of this project was a complete, playable hardware Connect 4 game system that showcased fundamental digital design principles, from FSM logic to real-time display output.

NYC Transportation Data Science Project

December 2024 – January 2025

This project focused on analyzing New York City's (NYC) transportation and crash rates using Python and Google Colab. Sliders

Released Click the Sliders logo above to play!

This personal project focuses on the creation of a sliding puzzle game, "Sliders". Players can choose from difficulty levels with grid sizes ranging from 3x3 (easiest) to 7x7 (hardest). The goal is to slide the numbered tiles into a specific randomized order, which is different for each game played. The numbered tiles don't need to be in a numerical sequence; the order will vary with each new game. The puzzle game offers an engaging challenge with various levels of complexity, suitable for both beginners and puzzle enthusiasts.

The game has been released as of December 2025, with more updates to come in order to improve user experience and engagement with this strategy-based puzzle game.

Jumbled Blockers

In Progress Target Release: Summer 2026

"Jumbled Blockers" is a brain-stimulating puzzle game where the objective is to arrange colored discs onto matching color-coded poles. Players can only move the top disc on any pole, one disc at a time. The game allows players to choose the difficulty by selecting how many poles to sort discs from, ranging from 4 to 7 poles. The number of discs a pole can hold is also determined by the difficulty level (in a 1:1 ratio).

The objective is to sort all the discs by color in as few moves as possible while keeping track of the limited pole capacity and disc order restrictions. Each puzzle is timed, adding an extra layer of competition. The game is intended to be engaging, helping players improve their problem-solving skills while offering various levels of difficulty.
